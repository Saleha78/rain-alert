# 🌧️ Rain Alert

A Python automation project that checks the weather forecast
and sends an email alert when rain is expected.

## Features
- Fetches weather data using OpenWeatherMap API
- Checks upcoming forecast conditions
- Sends a rain alert through email
- Runs automatically using GitHub Actions
- Uses GitHub Secrets for sensitive credentials

## Technologies
- Python
- Requests
- OpenWeatherMap API
- SMTP / Gmail
- Twilio
- GitHub Actions
